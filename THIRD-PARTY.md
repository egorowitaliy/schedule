# Сторонние компоненты

Schedule не включает PHP-фреймворки, пакеты Composer, библиотеки JavaScript, наборы шрифтов или внешние изображения.

Для работы используются компоненты, установленные на сервере отдельно:

- PHP и PHP-FPM — по лицензии PHP License;
- SQLite — общественное достояние (public domain);
- nginx — по лицензии BSD-2-Clause.

Эти компоненты не входят в архив выпуска Schedule. Их версии и лицензионные файлы предоставляет операционная система сервера.
